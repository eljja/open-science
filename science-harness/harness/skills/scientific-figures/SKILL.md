# 출판 품질 그림 (scientific-figures)

## 0. 시작
```python
from sciharness.figures import apply_figure_style, save_figure, panel_letter, FOCAL, NEUTRAL, ALARM, CATEGORICAL
apply_figure_style(lang="ko")          # 한국어 글꼴 자동 탐색(Malgun Gothic 등), 3단 글자 크기 (8, 7, 6)
fig, ax = plt.subplots(figsize=(3.4, 2.6))   # 단일 칼럼 ≈ 3.4in, 이중 칼럼 ≈ 7.0in
...
meta = save_figure(fig, "outputs/figures/fig01_<내용>", caption="...", data=df_behind_figure)
```
`save_figure`는 PNG+SVG 저장, 텍스트 겹침 검사, 사이드카 `*.figure.json`(캡션·해시·패널 크롭 좌표), 그림 뒤 데이터 CSV를 남긴다.
sciharness 가 없는 환경(Claude.ai 등)에서는 이 스킬 폴더의 `scripts/figures.py` 를 `sys.path`에 추가해 같은 함수를 쓴다.

## 1. 데이터 충실성 (위반 = 오류)
- 제외/플래그된 행은 요약 통계에 넣지 않는다. 그리려면 속이 빈 마커로 구분하고 범례에 명시.
- 조건이 다른(N, 프로토콜, 초기화가 다른) 군은 같은 축의 동등 비교로 그리지 않는다.
- 제목·범례·임계선이 모든 표시 데이터와 모순되지 않는지 저장 전 확인. 주장형 제목은 모든 범주에 대해 참이어야 한다.
- 요약 표시(평균, 막대)가 있는 패널은 n 과 반복 단위를 그림 또는 캡션에 쓴다.
- 같은 수치는 모든 패널/캡션/본문에서 같은 값 하나만 쓴다.
- 수치 진본성 라벨: 측정(measured) / 계산·모의(simulated) / 설명용(illustrative). 설명용 데이터 그림은 캡션에 반드시 표시.

## 2. 라벨 경제
- 하한: 모든 계열/마크가 그림만 보고 식별 가능해야 한다(“기준선” 같은 역할어 금지, 실체 이름으로).
- 상한: 패널당 제목+축+눈금+계열 식별 외 서술 주석 2~3개. 넘치면 캡션으로.
- 제목은 결론 문장(“처리군 중앙값이 더 높음”), 지표 이름은 축에.
- 값 표기는 인용될 핵심 수치 하나만. 유효숫자 2자리(구분이 사라지면 한 자리 더).
- 큰 수는 k/M/B, 내부 코드명 대신 읽을 수 있는 이름.

## 3. 축과 스케일
- 축 범위는 데이터보다 마커 반지름 이상 여유(`ax.margins(0.04)`).
- 데이터가 축의 40% 미만이면 축을 끊거나 데이터 바닥에서 시작(0 아님을 눈금으로 명확히).
- 로그축 위에 채운 막대 금지(점 + 중앙값 눈금 사용). 로그 눈금은 10², 1k 등 읽기 쉬운 형태.
- 소배수(small multiples)는 축 공유, 바깥 패널에만 눈금 라벨.
- 좋고 나쁨의 방향이 자명하지 않으면 “높을수록 좋음” 표시를 행당 한 번.

## 4. 색
- 같은 실체는 그림 전체에서 같은 색(색이 곧 상호참조).
- 주인공 계열은 FOCAL(진한 남색), 비교 대상은 NEUTRAL(회색)·얇은 선. 범주형 팔레트와 주인공 색은 겹치지 않음.
- 빨강/초록 대비로 이분 구분 금지(CVD). ALARM(주황-적색)은 오류/이상치 전용.
- 연속값 viridis 계열, 부호 있는 값은 발산형(RdBu_r)을 **의미 있는 0(또는 1.0)** 에 중심.

## 5. 글자
- 글자 크기는 역할별 최대 3단(제목/축 = 기본, 범례/주석 = 한 단계 아래, 눈금 = 두 단계 아래). 패널 문자만 예외(굵게, 축 밖 좌상단: `panel_letter`).
- 학명·유전자·변수 등 관례상 이탤릭은 이탤릭.

## 6. 데이터 형태별 권장
| 데이터 | 권장 |
|---|---|
| 범주×수치, 작은 n | 지터 산점 + 중앙값 눈금 |
| 범주×수치, 큰 n | box/violin |
| 연속 계열 | 평균선+마커, 개별 반복은 얇고 투명하게 뒤에; 범례 대신 선 끝 직접 라벨 |
| 행렬 < 200칸 | 모든 칸에 값 인쇄, 임계값은 컬러바 라벨에 |
| 임베딩(UMAP/PCA) | 눈금 제거, 모서리 축 화살표, 군집은 지시선 라벨 |
| 이름 있는 산점 | 최대/최소/플래그 점은 직접 라벨 |

## 7. 렌더 후 검증 (필수)
1. `save_figure` 출력의 `overlaps` 가 0 이 될 때까지 수정(이동/축약/엇갈림).
2. **이미지를 직접 본다**: `view_image(path)` (science-kernel MCP) 또는 클라이언트의 이미지 읽기 도구. 패널별로 `meta["panel_crops"]` 좌표로 크롭해 확인.
3. 확인 항목: 모든 글자/마크가 배경 대비 읽히는가, 가장 작은 요소에 윤곽이 있는가, 지시선 교차, 혼동되는 색, 범례가 해당 데이터 옆에 있는가, 잘린 글자.
4. 통과한 패널은 다음 수정 라운드에서 장식을 더하지 않는다.
5. 검증을 마친 그림만 `artifact_save` → 보고서에 삽입.

## 8. 다중 패널 그림
- 한 그림 = 한 메시지. 각 패널은 그 문장을 진술/뒷받침/한정한다.
- 측정 대상을 먼저 보여준 뒤 결과(개념도 → 데이터 순서).
- 12칸 격자로 패널 폭을 배정하고 `fig.subplot_mosaic` 사용. 복잡하면 `figure-critic` 서브에이전트로 패널별 적대적 검토.
