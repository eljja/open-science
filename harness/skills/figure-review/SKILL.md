# 그림 검토 (figure-review)

## 절차
1. 대상 PNG 와 사이드카 `*.figure.json` 을 읽는다(캡션, overlaps, panel_crops, data_csv).
2. `view_image(png)` 전체 1회 + `panel_crops` 의 각 패널 크롭 1회씩.
3. `data_csv` 가 있으면 제목/주석의 주장을 데이터로 확인(예: “더 높음”이 모든 범주에서 참인가).
4. 아래 표로 위반을 기록. **근거 없는 지적 금지** — 각 항목에 무엇을 보았는지 쓴다.

| 등급 | 예 |
|---|---|
| Tier-1(구성) | 패널 순서/메시지 불일치, 비교 불가 군을 동등 비교, 한 그림 두 메시지 |
| Tier-2(패널) | 텍스트 겹침, 잘림, 대비 부족, 빨강/초록 대비, 로그축 막대, 범례가 먼 곳, n 누락, 제목-데이터 모순 |
| 통과 | 해당 없음이면 쓰지 않는다(아첨 금지) |

5. 최대 8개, 심각한 순. 수정은 직접 하지 않고 지시만(수정은 작성자가 하고 다시 검토).
6. 통과한 패널에는 새 장식을 요구하지 않는다.

## 출력 형식
```
결과: 통과 | 수정 필요
- [Tier-2][패널 b] '처리' 라벨이 y축 눈금과 겹침 (크롭 b 좌하단) → 라벨을 x=1.05 로 이동
deviations: 없음 | (검토하지 못한 패널/파일)
```
